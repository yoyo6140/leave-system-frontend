# 知識庫測試用範例文件

這份檔案只是給你複製貼上用的草稿，不會被程式讀取，也不用進版控當正式文件。
下面有兩份獨立的範例，對應到 `/knowledge-base` 新增文件表單的「標題」「內容」「類型」三個欄位，請分別複製貼上，不要整份一起貼。

---

## 範例一：內部公文（type 選 `letter`）

**標題**

```
總務部函：辦公室搬遷作業及門禁卡更換事宜
```

**內容**（整段複製，`letter` 類型不會被切段，會原樣存成一個 chunk）

```
受文者：全體同仁
發文單位：總務部
發文日期：114年12月1日
發文字號：總務字第1140000123號
主旨：為配合辦公室整修工程，訂於114年12月15日至12月19日進行辦公室搬遷作業，並同步更換門禁卡系統，請同仁配合辦理，請查照。

說明：
一、本公司辦公室因應整修工程需要，原三樓辦公區域將暫遷至五樓會議室旁之臨時辦公區，搬遷期間請同仁自行將桌面個人物品、文件打包裝箱，紙箱由總務部於12月12日統一發放。
二、搬遷期間（12月15日至12月19日）以居家辦公方式處理公務，不需到臨時辦公區，仍須依規定於打卡系統辦理簽到退，比照正常出勤認定，不適用請假規定。
三、原有門禁卡將於12月20日起全面失效，新門禁卡將於12月18日起依各部門排定時間至總務部1樓服務台換發，請同仁攜帶員工證辦理。
四、如遇特殊情況需於搬遷期間進入原辦公室，請提前一日向總務部報備，並由專人陪同進出。
五、本次搬遷相關問題請洽總務部分機123或信箱 facility@example.com。

正本：全體同仁
副本：人力資源部、資訊部
```

## 範例二：人事請假補充規定（type 選 `rule`）

**標題**

```
人事請假補充規定
```

**內容**（整段複製，`rule` 類型會依空行切成多個段落）

```
總則：本補充規定依勞動基準法及其施行細則訂定，凡本法未規定事項，以本規定為準，如有疑義，以本公司人力資源部解釋為準。

病假佐證文件：員工請病假一日以上，應檢附合格醫療機構開具之診斷書或就診證明；病假三日以上者，除診斷書外，應另檢附勞工保險普通事故給付申請書（如有申請給付之需要）。未檢附證明文件者，人資得要求以事假或特休抵充，經主管同意者不在此限。

特休保留與展延：員工當年度特別休假未休完之日數，依勞動基準法第38條規定，雇主應發給未休畢日數之工資；惟員工如於年度終結前一個月內以書面向主管提出申請，經部門主管及人力資源部核准後，得將剩餘特別休假日數保留至次一年度6月30日前休畢，逾期未休畢者，視為同意雇主發給工資，不得再要求展延。

喪假證明文件：員工因直系親屬或配偶直系親屬死亡請喪假者，應於請假後7日內檢附訃聞、死亡證明書或相關證明文件至人力資源部存查，未能及時提出者，應先敘明理由，並於30日內補附，逾期未補附者，原核准之喪假將轉以特休或事假抵充。

請假申訴：員工對假單審核結果有異議者，得於收到審核結果7日內，以書面向人力資源部提出申訴，由人力資源部召集相關主管於14日內召開審議會議，並將結果以書面通知申請人，審議結果為最終決定。

婚假與陪產假：員工本人結婚者，得於結婚登記日前10日至後1年內，自行決定連續或分次申請8日婚假；員工配偶分娩者，依規定得申請7日陪產及陪產檢假，應於配偶預產期前後15日內申請完畢，逾期未申請者視為放棄。

加班換休：員工延長工時依規定得選擇領取加班費或換取補休，換取補休者應於換休期限（原則為核發加班費之次日起一年內）休畢，逾期未休畢者，公司應於期限屆至後30日內給付加班費差額。
```

### 小提示

這兩份範例故意涵蓋了你之前測試「沒有足夠資訊」時問過的題目（病假診斷書、特休保留、喪假證明、請假申訴），上傳之後可以拿同樣的問題再測一次，應該會從「沒有足夠資訊」變成有實際根據的回答，順便驗證新文件真的有被檢索到。
